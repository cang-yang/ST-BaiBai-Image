# RunningHub 图片渠道

## 安装

在 SillyTavern「扩展 -> 安装扩展」填入：

```text
https://github.com/cang-yang/ST-BaiBai-Image
```

本 fork 的默认分支为 `feat/runninghub-image`，包含构建后的 `dist/`。
最低 SillyTavern 版本沿用上游：1.12.13。
不要同时安装或启用两份柏宝绘：它们共享设置键、聊天卡片和公开接口。

已有 Git 安装可先备份 SillyTavern 数据，在**原扩展目录**检查 `git status`，
确认没有需要保留的本地修改后切换远端及分支：

```sh
git remote set-url origin https://github.com/cang-yang/ST-BaiBai-Image.git
git fetch origin
git switch --track origin/feat/runninghub-image
```

已有同名本地分支时用 `git switch feat/runninghub-image`。不要使用强制重置覆盖自己的修改。
刷新酒馆页面。本 fork 的更新检查指向自身分支，不检查原作者的版本号。
如果原安装不是 Git 仓库，先备份、卸载原扩展，再从本 fork 安装；不要删除酒馆用户数据。

## 首次配置

1. 在 RunningHub 保存可正常运行的图片工作流，取得该工作流的 ID 和 API 格式 JSON。
2. 打开柏宝绘「渠道 -> RunningHub」，选择与账号匹配的 `.ai` 或 `.cn` 站点，填写 API Key。用 `+` 可新增多条 Key，每条可命名、启停、设置并发上限。
3. 点单条「测试连接」或「测试全部 Key」。此操作仅查询账号信息，不提交图片生成。
4. 导入工作流 JSON。支持 `{ "name": "...", "workflowId": "长数字字符串", "workflow": "API JSON 字符串" }`、`workflow` 为对象的包装，以及裸 API JSON。裸 JSON 导入后需要补填工作流 ID。
5. 在「工作流参数」检查提示词为插件自动填入。展开「全部参数」可按节点查看和搜索；点参数旁的星标加入常用设置。普通提示词可以在其前后保留质量词，但 MOSS Layout JSON 应保持完整，不在 JSON 前后拼标签。LoRA、模型、采样器、步数等可以直接编辑为固定值。
6. 先试生成一张，确认成功后点「使用此渠道出图」。试生成、楼层配图与公开生成接口都会按 RunningHub 账号规则计费。

**必须使用 API 格式，不是带 `nodes` / `links` 数组的 ComfyUI 界面格式。**
工作流 ID 必须是带引号的字符串，避免 JavaScript 对长整数舍入。
模型页的 ID 不等于工作流 ID。

## 参数与导入兼容

| 占位符 | 含义 |
| --- | --- |
| `%prompt%` | 本次剧情生成的正面 tag / MOSS JSON |
| `%negative_prompt%` | 本次动态负面词，可与固定负面词组合 |
| `%nl%` | 自然语言描述；启用生成自然语言后按工作流需要绑定 |
| `%width%`、`%height%` | 所选横竖画幅的像素尺寸 |
| `%seed%` | 本次生成种子 |

同时识别 `%提示词%`、`%正面提示词%`、`%负面提示词%`、`%宽度%`、`%高度%`、`%种子%`。
其他占位符会阻止提交，需要在节点编辑器中改成固定值。
只对节点 `inputs` 中的标量进行替换，不用字符串拼接构造 JSON，提示词的引号、反斜杠和换行保留原样。

所有标量输入都会发送给云端，包括固定正负提示词和 LoRA 权重。
**本地 JSON 不能替换云端节点连接、节点类型或新增节点。**
云端工作流拓扑必须与导入文件一致，模型和 LoRA 必须已在该云端工作流中可用。
修改拓扑后应先在 RunningHub 保存，再重新导入对应 API JSON。

固定尺寸、固定种子不会被横竖尺寸输入框或试生成种子覆盖。
要使用每次生成的种子，须将采样器 `seed` / `noise_seed` 绑定到 `%seed%`；
同理，宽高字段需要绑定尺寸占位符。图库外层记录的是本次请求的种子/尺寸，
工作流有固定值、多采样器或中间缩放时，应以云端实际结果及任务记录为准。

自然语言开关决定 AI 是否生成描述，不会自动修改工作流。需要描述的文本字段可填 `%prompt%\n%nl%`。
RunningHub 与 ComfyUI 共用柏宝绘的工作流提示词规范和漫画 Layout 配置，不支持 NAI 原生的 `characters[]`。
MOSS 漫画坐标转换同时在公共生成入口和面板试生成执行。漫画模式启用时，输入带 `layout` 和逐项 `panel` / `slot` 的符号 JSON，插件按实际尺寸转换为原生 bbox。
工作流文件可设置 `baibai.manga: true`，导入后弹出确认框；确认才会开启全局漫画模式，并把现有版式缩放到工作流尺寸。
也可手动点「应用漫画配置」。横竖尺寸须互为宽高交换，例如 `1664x2496` / `2496x1664`。
会保留自定义版式内容及启停状态，但缩放影响所有共用漫画配置的工作流，不会自动更改云端节点拓扑。
「工作流参数」在没有工作流或 JSON 错误时显示明确原因，不会展开成空白。

### 通用参数编辑器

常用设置默认显示布尔开关、直接填写的步数 / CFG / 降噪 / 模型强度。
任何标量参数都可以用星标加入或移出常用设置；全部参数仍完整保留，按节点分组，
支持搜索原节点名、节点 ID、参数原名和显示名称。参数下的「显示名称」可自定义，
只影响本地显示，不修改云端节点名、参数名或数值。

控件依实际标量类型显示为开关、数值输入或文本输入，不根据某个模型或工作流猜测用途。
例如 `true` / `false` 的作用以工作流作者的节点名及连线为准，不自动命名为快速 / 标准。
API JSON 没有提供候选列表时保留可编辑输入，不编造模型、采样器或自定义节点的选项。
带明确 `baibai.parameterControls` 定义的文件可提供真实的下拉选项，例如：

```json
{
  "parameterControls": [
    {
      "nodeId": "20",
      "fieldName": "value",
      "label": "作者定义的开关",
      "common": true,
      "options": [
        { "label": "方案 A", "value": true },
        { "label": "方案 B", "value": false }
      ]
    }
  ]
}
```

以上为包装文件 `baibai` 内的可选字段，任何节点 ID 均可使用。
只接受非空名称、标量选项及匹配的类型；失效字段显示提示并退回通用编辑。
没有这段定义也能正常导入和编辑。API 文件未导出的纯前端开关 / 绕过状态不是可提交的节点参数，
本地编辑器不会伪造这种控制，需要先在云端保存实际分支或暴露对应输入。

宽高、种子和提示词的动态来源单独显示；要改变来源，在对应参数下展开「参数来源」。
修改项有标记和单项恢复按钮；全部恢复需要确认，只恢复已有同类型节点的标量值，
不恢复连线、不影响账号、配图预设和漫画版式。新导入保存导入时参数为基准；
旧工作流首次升级以当时保存的参数为基准，不会还原到未知的作者原版。
名称、常用设置、可选定义及恢复基准随工作流导出，不包含渠道 Key。

漫画预设的 `baibai.mangaPositive` 是固定正面画风词。编译坐标后，它会合并到原生 JSON 的
`summary.caption` 中，不会把完整 JSON 拼坏，也不固定本次剧情、人物或台词。
负面词仍配置在工作流节点内；需要生成对白的漫画不应使用禁止 `text` 的普通插画负面词。

成套配置可附带 `baibai.mangaBundle`，字段为 `spec`（漫画规范）、`thinking`（漫画检查指导）、
`selectionNotes`（版式选择补充）、`custom`（自定义版式数组）。
导入只保存预设，**确认“应用漫画配置”后**才覆盖全局规范、检查指导和选择说明；同 ID 版式会更新，
其他版式及启停状态保留。分享前检查附带文档是否包含私人信息或不适合接收者的内容。
世界书 JSON 不属于工作流，导入器会给出明确提示，应到酒馆世界书界面单独处理。
出框使用实际越过 F 的 S/L/R 主体区域，并配合人物与背景的遮挡描述；不能仅靠增加质量词保证效果。

## 参考图与输出

输入名为 `image` 的节点提供参考图上传，支持 PNG / JPEG / WebP，最多 10 MB。
上传成功后写入 RunningHub 返回的文件名，而不是本地磁盘路径，并将工作流绑定到上传使用的 Key。
私有工作流也可在「生成 Key」指定账号。只有确认工作流及输入文件对池中所有账号均可用时，才选自动分配。
当前是工作流级固定参考图，不会自动从聊天附件或角色头像选择图片。

默认取结果中的第一张图片，也可以选择 SaveImage / PreviewImage 输出节点。
自定义图片输出节点可在导出文件的 `baibai.outputNodeId` 中指定。
单次调用返回一张图；视频、音频、压缩包不作为图片导入。
下载支持 PNG、JPEG、WebP、GIF、AVIF、BMP，最多 50 MB，远端地址须为 HTTPS。
试生成图片可保存到图库或直接下载；聊天配图仍走柏宝绘原有落盘和卡片流程。

## 排队、取消与恢复

多 Key 默认自动分配到有空位的账号；没有空位时在本地排队。默认每个 Key 在**当前页面**最多同时执行一个请求，各自上限可调至 5。
相同密钥重复填写不会叠加并发。此限制不协调其他标签页、设备或插件；多条 Key 属于同一平台账号时，仍可能共享云端额度。
任务创建时保存配置快照，后续启停或编辑 Key 只影响新任务；已排队/已提交任务不会被重定向。
生成、查询及取消使用同一条 Key 和站点。没有自动换 Key 重发机制，避免不确定的提交结果造成重复扣费。
旧版单 Key 配置会迁移为列表，保留原并发上限。纯串行的场景只需保留一条 Key。
等待超时默认 10 分钟，可设 1 至 60 分钟。

创建任务只提交一次。网络失败或提交超时时，即使没有拿到任务 ID，云端也可能已经接单：
插件不会自动重发；请先检查 RunningHub 任务记录。
只对查询状态的短暂失败做有限重试，不会借此重新生图。

拿到任务 ID 后可在「恢复已有任务」重新获取结果，不创建新生成任务。
本次会话已记录的任务优先使用原 Key 和站点恢复；原 Key 删除时提示恢复该配置，不冒用其他账号。
刷新后的未知任务使用「上传 / 恢复任务 Key」中选择的账号。结果能否恢复取决于平台的任务保留期限、Key 权限和文件是否仍可下载。
本次会话任务列表只存在当前页面内存中，刷新会清空；需要恢复时从 RunningHub 任务记录取得 ID。

本地排队期间取消不会提交任务；已提交后取消会调用云端取消接口。
**取消不保证不扣费或退款**，可能因任务已完成或网络失败而不能撤回。
恢复任务时取消只停止本地查询，不会取消原云端任务。
不要在生成期间刷新或关闭酒馆页面，否则可能留下正在运行的云端任务。

## 费用、冷启动与隐私

默认实例、保留时间 0、不启用付费保活。`Plus` 和实例保留需用户主动选择。
保留时间接受 10 至 180 秒，仅适用于平台支持的企业共享 Key，保留期间可能额外计费。
这些选项不保证消除冷启动，平台额度、计费、排队与保活资格以账号当时规则为准。
界面的费用和云端耗时只展示服务端实际返回值，缺失时不猜测。

Key 按现有渠道的方式存入酒馆服务器设置，**不是加密保险库**；管理员、设置备份和同源脚本可能访问。
工作流导出不包含渠道 API Key 或本地账号绑定。节点内容本身可能带有用户手写的凭据，分享前仍应检查 JSON。
Key 只发送到允许的 RunningHub 官方站点，不附加到结果图片 CDN 下载请求，也不放进任务列表或日志。
浏览器跨域策略、网络代理、平台域名及文件 CDN 的 CORS 设置可能影响使用。

## 实现与验收边界

参考智绘姬的图片工作流交互与 RunningHub API 合约，在柏宝绘自己的 TypeScript/Vue 后端和公共生成入口中独立实现，
没有拷贝智绘姬打包后的实现代码，也没有迁入视频逻辑或改变上游版权声明。

- 参考项目：`damoshen123/st-chatu8`，分析基线 `6e159481b15a975ba4ab2ba43d449d659eca6cd5`。
- 目标上游：`wuhehen176/ST-BaiBai-Image`，基线 `6943e13cf7660f14b164b1e08de4f3c290034506`。
- 创建/查询：`POST /openapi/v2/run/workflow/{workflowId}`、`POST /openapi/v2/query`。
- 取消/上传/账号：`POST /task/openapi/cancel`、`POST /task/openapi/upload`、`POST /uc/openapi/accountStatus`。
- 0.3.4 补充多 Key 并发、账号绑定、节点参数空状态、漫画尺寸联动、固定画风词及漫画成套配置。不迁入视频生成或视频参考素材处理。
