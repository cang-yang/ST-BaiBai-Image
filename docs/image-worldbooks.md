# 生图世界书

入口：设置 → 生图世界书。导入酒馆原版世界书 JSON 即可，支持多文件。
同名文件导入为带编号的新副本，不覆盖旧书。导出仍是酒馆世界书格式。
导入只写入 `extension_settings.baibai_image.imageWorldbooks`，不会创建酒馆世界书、
修改全局选书或绑定角色。若同一本书已经在酒馆中全局启用，本功能不会替你停用它。

## 导入兼容处理

导入与扫描前均使用同一固定版本的酒馆原版字段模板及补全函数：
缺失字段补为原版默认值，非数组的主/附加关键词修复为空数组，
空或无效的角色过滤配置修复为不限制角色。修复为空数组不等于猜测或拆分关键词。
`role: null` 和 `selectiveLogic: null` 按原版扫描器的默认身份和默认附加逻辑处理。
合法的 `0`、`false`、可空匹配设置以及未知扩展字段保留，不使用真假值判断替换默认值。

仍会拒绝无法使用的数据，例如数字正文、含非文本元素的关键词数组或越界插入位置；
错误会标出对应条目。单书 2 MB、2000 条、单条正文 100000 字符和总书库 10 MB
是插件的资源保护限制，不是酒馆原版限制。当前仅接收酒馆世界书 JSON，
不包含 PNG 内嵌世界书或其他软件格式的转换。

## 使用范围

- 只参与自动生成 tag / 漫画 Layout 的独立文本请求；直接提交已有图片提示词不经过这一步。
- 与 RunningHub、ComfyUI、NAI 无关，不把世界书原文塞进云端工作流节点。
- 副 API 未配置而借用主 API 端点时，仍是独立的 tag 请求，不写入正文提示词。
- 原有的角色卡、全局世界书参考逻辑保留。生图私有书不受共享的“排除世界书”设置控制。
- 单书启停、条目启停、常驻/关键词、搜索、批量启停、编辑和删除在插件内生效。
- 默认编辑页只显示标题、使用时机、触发词和正文。高级设置按用途折叠；
  “编辑原始数据”可以编辑角色过滤等全部原版字段，未知扩展字段会保留。
- 每个关键词占一行，正则中的逗号不会被拆分。

## 原版扫描核心

使用固定版本的 SillyTavern 原版扫描核心，源码版本与授权见 `THIRD_PARTY_NOTICES.md`。
不是调用共享全局扫描器，也不会临时更改酒馆的全局选书。

保留四种次关键词逻辑、大小写/整词/正则匹配、扫描深度及覆盖、概率、递归、
递归排除与延迟级别、最少激活、预算与忽略预算、互斥组权重/优先/评分、
黏性/冷却/延迟、角色过滤、生成类型过滤和原版激活装饰器的算法。
正文按最新消息优先、隐藏消息排除的方式送入扫描器。

默认读取酒馆的扫描设置；可复制为插件独立设置。预算基数是插件配置的副 API
上下文大小（默认 8192），并不自动猜测副 API 模型的真实上下文上限。
有宿主分词器时使用它，否则按字符估算；宿主和副 API 分词器可能不同。
扫描总轮数有 2000 轮安全上限，超限会明确报错，不静默截断后继续出图。

黏性和冷却保存在当前聊天的 `baibai_image_worldbook` 私有字段内，
按可见聊天消息数推进，不按图片数推进。预览扫描不落盘，概率/互斥组随机结果
可能与下一次实际请求不同。重新生成历史楼不会覆盖较新楼的计时状态。

## 局部上下文的映射

主对话和生成 tag 请求的结构不同，插入位置只能在副请求内映射：

- 角色定义前/后：对应副请求内的角色参考区前/后。
- 示例消息前/后：对应参考区前/后；不会改写主聊天示例。
- 作者注前/后：位于副请求任务正文之前，按前/后顺序排列；不修改酒馆作者注。
- 聊天深度与角色：按副请求消息数组插入，保留 System/User/Assistant；
  不越过固定输出协议前缀，避免 DSH 会话把动态世界书缓存成固定规范。
- Outlet：只替换本次副请求动态消息中的 `{{outlet::名称}}`。
  不引用的 Outlet 不注入，也不在固定规范中展开动态 Outlet。

因此，“原版触发算法”不意味着主对话的插入位置会原封不动作用到副请求。
这层映射是明确的局部适配，不承诺与未来版本或第三方扩展的所有行为完全相同。

## 隔离边界

支持只读宏 `char`、`user`、`persona`、`description`、`personality`、`scenario`、
`getvar`、`getglobalvar`。不执行写变量宏、EJS、脚本、自动化 ID、
外部强制激活、向量扩展的语义召回、全局正则扩展或全局扫描事件。
相关原始字段保留；导入后在兼容性提醒中可见，不会静默假装执行成功。
向量条目仍能由它们原有的关键词或常驻规则激活。

这部分限制是为保证“只在插件局部生效”：书里的第三方脚本不应修改主聊天状态。
若确实需要第三方脚本能力，应该单独设计并确认其权限，而不是直接执行导入文件。

## 验证

定向单元测试覆盖原版核心规则、JSON 往返、并发隔离、计时、预览不落盘、
主聊天状态不变、私有条目进入动态 tag 消息和 DSH 固定前缀保持。
浏览器冒烟测试在隔离宿主页面运行，不等同于所有酒馆版本/扩展组合的真实环境验证。
