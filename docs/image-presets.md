# 正文配图预设

这是柏宝绘自己的提示词预设库，不是工作流库，也不是对智绘姬全部任务档案的复制。
提示词只有一个设置入口：**设置 → 正文配图预设**。原“自定义提示词”和漫画的创作规范已合并到这里；API、工作流节点参数与漫画版式仍在各自页面。

## 日常使用

1. 点击“新建”，或选中已有预设点击“编辑”。内置默认需先“复制并编辑”。
2. 点击“使用此预设”。切换只影响下一次图片提示词请求，不影响主 API 续写正文。
3. 需要分享时导出 JSON；导入后先检查，再手动启用。导入不会覆盖同名预设。
4. 想恢复插件默认规则，选择“内置默认”并点击“使用此预设”。想恢复升级前的自定义内容，选择“原有提示词（已迁移）”。

编辑器分为三个页签：

- **画面要求**：内容、风格、示例与条件条目。
- **书写规范**：按普通配图、漫画和 NovelAI 场景分别保存规范与检查指导；每项可选“内置参考”“本预设自定义”或“不附加”。
- **高级**：工具输出、工作流提示词格式、通用前置规则与局部变量。

预设列表下方显示当前或所选预设的规则来源；未启用的选择和未保存的草稿都有明确标记。
每份预设独立保存规则，不再实时继承另一处全局自定义文本。内置参考随插件更新；需要固定文本时切为“本预设自定义”。

每份预设可以新增、停用、排序和编辑条目，条目有 system/user/assistant 三种消息角色。
条件条目匹配**本次携带的此前上下文与目标正文**。关键词用英文逗号、中文逗号或换行分隔，区分英文大小写，按普通子串匹配；第一组任一词命中后，填写了第二组时还须命中第二组任一词。不是正则，也不冒充酒馆世界书扫描规则。需要酒馆完整触发逻辑时使用“生图世界书”。

预设只写画面偏好与提示词要求即可。插件自动附加：

- 目标正文和有效的 P 位置、上下文、角色卡、人设、角色固定外貌库和可用记忆。
- 已触发的世界书，包括独立生图世界书，仍按原来的位置与深度注入。
- 当前图片数量、画幅方向和输出协议。
- 本预设选用的规范与检查指导；设置为“不附加”即不发送该项。**漫画 Layout 的坐标与输出结构约束仍保留**，避免无效格式。

新建预设默认不附加通用前置规则；“内置默认”保留插件原有内置前缀，可以复制后自行关闭。
预设不能改变最终的图片插入协议；自由度用于内容、风格与组织消息，不用于绕开数据验证。

## 升级与漫画配置

首次升级会把旧全局自定义提示词、漫画规范与检查指导保存为“原有提示词（已迁移）”。原先没有启用自定义预设时，自动使用此迁移预设；原先已经启用预设时，保持选择，并把其原来继承的规则固化在该预设内。重复加载不会重复迁移。
旧字段仅作数据备份，之后修改预设不会再读写这些全局文本。

RunningHub 的“应用漫画配置”会把工作流附带的漫画规范存为一份新命名预设并启用，保留原预设。漫画版式编辑器只管理几何、画布和版式说明，不再管理创作提示词。
这些规则只进入图片提示词请求，不写入主 API 的正文生成配置。

## 内容变量

正文等数据自动随请求发送，通常无需手动插入变量。需要在特定条目中引用时可以使用：

| 变量 | 内容 |
| --- | --- |
| `{{story}}` | 带 P 编号的目标正文 |
| `{{context}}` | 本次携带的此前上下文 |
| `{{character}}` / `{{persona}}` | 角色卡 / 用户人设 |
| `{{worldbook}}` | 原全局世界书路径取得的文本；独立生图世界书仍按自己的规则注入 |
| `{{library}}` / `{{memory}}` | 角色固定外貌库 / 柏宝书记忆 |
| `{{task}}` | 单图重写等本次任务备注 |
| `{{user}}` / `{{char}}` | 用户 / 角色名字 |
| `{{min_images}}` / `{{max_images}}` | 本次要求的图片数量范围 |

在“高级”中添加自己的名称与文本后，用 `{{名称}}` 引用。也支持顺序执行的局部文本赋值 `{@setvar::名称::文本@}`、读取 `{@getvar::名称@}`，以及 `{{roll 6}}`。
变量只在本次请求中存在，不读写酒馆聊天变量或全局变量。替换进去的正文和变量值不会再次当作代码或宏执行。
未提供的变量会阻止请求，并列出名字，不会悄悄替换为空串。

## 工具输出、流式与直连

“普通文本”让模型返回 JSON；“工具输出”使用唯一的数据工具 `submit_image_plan`，其参数就是同样的配图 JSON。
工具不能执行命令、读取文件或自行调用生图后端。只有完整输出通过位置、数量与字段校验后才进入原有配图流程。
未知工具、多个调用、损坏的参数、被截断的输出均报错，不使用半截内容生成图片。

工具模式需要**独立副 API 渠道和支持 OpenAI 兼容 tools 的模型/服务**。不支持时请改回普通文本，不会自动重复发送另一种请求。
渠道原有“流式传输”开关对普通文本与工具输出均生效，试运行可查看逐步返回的内容。
跟随主 API 使用酒馆 `generateRaw`，仍是非流式文本模式，不支持此处的工具参数。

在副 API 渠道编辑框选择请求方式：

- **酒馆转发**：默认。工具配置通过 custom 源透传。
- **浏览器直连**：浏览器直接向该渠道的 `/chat/completions` 或 `/models` 发请求，只发送 API 凭证，不携带酒馆 Cookie 或 CSRF 请求头。不绕过服务端的 CORS 或浏览器 HTTPS 限制。不可连接时改回酒馆转发。

请求方式是柏宝绘的私有渠道偏好，不改变柏宝书共享的 API 渠道结构，也不随预设导出。
DSH 持久会话支持仅调整书写规范的预设；暂不能与启用的非空画面条目、工具输出或浏览器直连组合，会在请求前给出明确错误。

## 本地检查与试运行

“本地检查”不调用副 API、不请求生图，检查条目和变量，并展开准备发送的消息。
留空测试正文使用当前聊天最后一条 AI 回复；填写文本则创建隔离的测试场景。生图世界书测试不推进私有计时状态。

“测试副 API”是**计费请求**，只请求并验证配图计划，不请求 RunningHub/ComfyUI/NAI、不写正文、不保存角色变化。
它使用同一消息构造与响应解析逻辑，但不是完整的出图质量测试。普通渠道可取消网络请求；跟随主 API 时取消只阻止使用结果，宿主内部请求可能仍在进行。
兼容性提醒并不代表某个第三方模型已经实测成功，应使用自己的渠道做一次试运行。

## 导入格式

支持以下明确格式，不猜测任意文件含义：

1. 柏宝绘原生格式，固定 `format` 和 `version`。当前导出 v2，同时兼容 v1；导入旧格式不会继承本机旧全局自定义文本。
2. `[{ "role": "system", "content": "..." }]` 消息数组，或 `{ "messages": [...] }`。
3. 包含 `entries` 的原生条目对象。
4. 智绘姬请求类型档案：只提取 `image_gen.context_profile` 指向的正文配图条目。
5. 智绘姬上下文预设名称映射，例如 `{ "预设名": { "entries": [...] } }`。

智绘姬转换保留条目顺序、名称、启用状态、消息角色、主/附加关键词。提供部分常用中文变量别名。
**不保证原文件开箱即用**：原来的 XML 输出、挂载正则、`display_stream`、`【ToolCall引导】`、专属服装库和角色占位符调用并非柏宝绘协议。
工具引导块或未提供变量会明确阻止请求；需要在编辑器修改或停用对应条目。旧 XML 指令应删除，最终始终遵守柏宝绘的 JSON 契约。没有复制外部项目的脚本执行、越权宏或其他任务引擎。

原生文件示例：

```json
{
  "format": "baibai_image_prompt_preset",
  "version": 2,
  "preset": {
    "name": "清晰叙事",
    "description": "主体明确、人物一致",
    "output": "text",
    "rules": {
      "comfySpec": { "mode": "builtin", "text": "" },
      "comfyThinking": { "mode": "builtin", "text": "" },
      "jailbreak": { "mode": "off", "text": "" }
    },
    "variables": { "画面偏好": "优先明确主体与自然光影" },
    "entries": [
      {
        "name": "基本要求",
        "enabled": true,
        "role": "system",
        "content": "忠于正文，保持人物外貌和场景连续。{{画面偏好}}",
        "trigger": "always",
        "keywords": "",
        "andKeywords": ""
      }
    ]
  }
}
```

ID 由导入器重新生成。单文件不超过 2 MB、单份最多 2000 条目，预设库不超过 10 MB。
导出不包含渠道、API 密钥或其他任务配置，但**你自己写进提示词或变量的私人文本会随预设导出**，分享前请检查。
