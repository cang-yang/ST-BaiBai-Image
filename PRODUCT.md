# Product

## Register

product

## Users

SillyTavern users configuring story illustrations on desktop and narrow mobile screens.
They need to understand the active preset without learning API protocol internals.

## Product Purpose

Turn story text into validated image plans and invoke the selected image backend.
Keep image-only rules separate from story generation.

## Brand Personality

Clear, restrained, dependable. Preserve the existing plugin theme and components.

## Anti-references

Avoid cockpit-like settings, unexplained protocol labels, nested decorative cards,
and a single entry title hiding several unrelated requirements.

## Design Principles

- Show what is active, where it comes from, and whether an edit is saved.
- Keep ordinary creative editing separate from transport details.
- Preserve existing user content and imports.
- Validate before paid image generation; report failures honestly.

## Accessibility & Inclusion

Use labeled native controls, keyboard-accessible navigation, visible focus,
wrapping text, and layouts that work on mobile without horizontal overflow.
